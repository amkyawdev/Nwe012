# AmkyawDev TTS - Myanmar Text-to-Speech

🎙️ AI Voice Studio for Myanmar language with natural-sounding voices.

## Features

- **Voice Studio** - Convert TTS and SRT text to speech
- **History** - View previously created audio files
- **API Settings** - Manage your API keys securely
- **Usage Limits** - 5,000 character limit per session
- **Two Myanmar Voices** - သီဟ (Male) and နီလာ (Female)

## Quick Start

1. Clone the repository
2. Open `index.html` in a browser
3. Add your Gemini API key in Settings

## Tech Stack

- Pure HTML5, CSS3, JavaScript
- Modern animations and transitions
- LocalStorage for state persistence
- Responsive design
