Text-to-Speech (TTS) ဆိုတာဘာလဲ?

Text-to-Speech (TTS) သည် စာသား (Text) ကို လူသားအသံနဲ့တူသော အသံ (Audio) အဖြစ် ပြောင်းလဲပေးသည့် နည်းပညာတစ်ခုဖြစ်ပါသည်။

မြန်မာစာ Support

မြန်မာဘာသာစကားကို သဘာဝကျအောင် ဖတ်ပေးနိုင်ပါသည်

🎨
Voice Options

ကျားအသံ (သီဟ) နှင့် မိန်းမအသံ (နီလာ) ရွေးချယ်နိုင်ပါသည်

📱
Multi-Purpose

Podcasts, Videos, Audiobooks, Accessibility စသည်တို့အတွက် အသုံးပြုနိုင်ပါသည်

SRT Format ဆိုတာဘာလဲ?

SRT (SubRip Subtitle) သည် Video subtitles/closed captions များအတွက် အသုံးပြုသည့် file format တစ်ခုဖြစ်ပါသည်။

SRT Example 
1
00:00:01,000 --> 00:00:04,000
မင်္ဂလာပါ

2
00:00:05,000 --> 00:00:08,000
ဒီဟာက စာသားဖြစ်ပါသည်

3
00:00:09,000 --> 00:00:12,000
Timecode format: HH:MM:SS,mmm
⏱️
Timestamp

အသံဖွင့်/ပိတ်ချိန်ကို သတ်မှတ်နိုင်ပါသည်

🎬
Video Subtitles

YouTube, ရုပ်သံများအတွက် subtitle ဖန်တီးနိုင်ပါသည်

API Key ရယူနည်း

1

Google AI Studio သို့သွားပါ

https://aistudio.google.com မှာ login ဝင်ပါ

2

API Key ဖန်တီးပါ

Sidebar မှ "Get API Key" ကိုနှိပ်ပြီး "Create API Key" ကို နှိပ်ပါ

3

Key ကို Copy လုပ်ပါ

ရရှိသော API Key ကို copy လုပ်ပြီး App မှာ ထည့်သွင်းပါ

API Type

Gemini (default) သို့မဟုတ် AI Studio ကိုရွေးချယ်နိုင်ပါသည်

Google Cloud TTS API ဖွင့်နည်း

Important!

API Key သုံးမယ်ဆိုရင် Google Cloud Console မှာ TTS API ကို enable လုပ်ဖို့လိုပါသည်

1

Google Cloud Console သို့သွားပါ

https://console.cloud.google.com မှာ login ဝင်ပါ

2

Project ရွေးပါ

API Key နဲ့ချိတ်ဆက်ထားတဲ့ Project ကို select လုပ်ပါ

3

Text-to-Speech API ကို Enable လုပ်ပါ

ဤလင့်ခ် မှာ Enable နှိပ်ပါ

4

စမ်းသပ်ပါ

၂-၃ မိနစ်စောင့်ပြီး App မှာ စမ်းသပ်ပါ
